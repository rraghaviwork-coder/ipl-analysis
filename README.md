# IPL Match Analysis Dashboard

A web dashboard analysing every IPL match from 2008 to 2026.

**Tech stack:** Python · Flask (web server + JSON API) · Pandas (analysis) · R (Elo ratings + statistical win model) · HTML/CSS + Chart.js (frontend)

## Features
- **Champions timeline:** winner, runner-up and final's Player of the Match for every season
- **Team performance:** total wins, win %, titles won, matches per season
- **Toss & strategy:** bat vs field choice, whether the toss winner wins, batting first vs chasing, trends by season
- **Head to head:** pick any two teams to see their record and every match between them
- **Players & venues:** most Player of the Match awards, top host cities
- **Ratings & match predictor (R):** Elo ratings for every team across all seasons, plus a logistic-regression
  win model (Elo gap, recent form, toss, batting order, home ground). It reports odds ratios and likelihood-ratio
  p-values, is evaluated on the latest 3 seasons (held out), and comes with a calibration chart and the biggest upsets.
  Pick two teams, the toss and the venue to get a pre-match win probability.
- A season range filter that updates the whole page (the R model always uses every season)

## Project structure
```
app.py               Flask backend: loads data, computes stats with Pandas, serves /api/*
templates/index.html Page layout
static/style.css     Styling (responsive)
static/app.js        Fetches the API and draws the charts with Chart.js
r/model.R            R: Elo ratings + logistic-regression model -> data/model.json
data/matches.csv     Dataset (downloaded automatically if missing)
data/model.json      Generated by r/model.R (served at /api/model, used by /api/predict)
```

## Dataset
IPL match-level data based on Cricsheet: https://github.com/ritesh-ojha/IPL-DATASET (`csv/Match_Info.csv`).
Renamed franchises are merged into their current names (e.g. Delhi Daredevils → Delhi Capitals).
In tied matches, the super-over winner counts as the winner.
The champion is the winner of each season's last match (the final).

## How to run
```bash
pip install -r requirements.txt
Rscript -e 'install.packages("jsonlite")'   # once; the R model needs only base R + jsonlite
python app.py
```
On startup the app runs `Rscript r/model.R` automatically when `data/model.json` is missing or older
than the data or the script. You can also run it yourself: `Rscript r/model.R`.

## What the R model found
IPL results are close to a coin flip: on 2024-2026 matches the model picks the winner about 52% of the time.
Only two factors are statistically significant at the 5% level:
- **Chasing helps:** batting first lowers the odds of winning by about 17% (odds ratio 0.83).
- **Home ground helps:** the odds of winning are about 16% higher (odds ratio 1.16).

Winning the toss has no effect on its own, and Elo and recent form are only weak signals.
